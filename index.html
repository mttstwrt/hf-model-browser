GGUF Model Finder

Search Hugging Face for llama.cpp models, see which quants fit your machine, and copy the command to run them.

Quantised KV cache needs --flash-attn on, which is appended to every command below. A prebuilt binary without flash-attention kernels will fall back to CPU attention silently — and run 25–45× slower.

How these estimates work

Each quant’s architecture is read straight from the GGUF file header over a ranged request — a few kilobytes, not the whole model. Weights are assumed to spread evenly across layers (file size ÷ layer count), and the KV cache is 2 × layers × KV heads × head dim × context at the selected precision. A 12% allowance is added on top for compute buffers and allocator slack.

These are ballpark numbers, not llama.cpp’s own sizing. Treat a result near the edge of your VRAM as “probably”, not “definitely” — real runs often need a little more than the arithmetic suggests. Mixture-of-experts and MLA architectures are the least accurate, since their cache does not follow the formula above.
